#### Q13 · MCQ · 1 mark(s) · Singly and doubly linked lists

Study: /#/lesson/linked-lists?tab=practice

**Approach:** Record head, tail and available predecessors. → Update links in a safe order. → Test empty, single-node and consecutive-match cases.

**Worked solution:**
1. Deleting the tail of a singly linked list requires finding its predecessor from the head. A pointer to the tail alone cannot perform the usual successor-copy trick. Worst case: O(n).
2. A doubly linked node has a predecessor pointer, so its neighbours and the head can be updated in O(1), including boundary cases.
3. Hence **D**: SLLdel O(n), DLLdel O(1).

#### Q14 · MCQ · 1 mark(s) · Regular expressions and closure

Study: /#/lesson/regular-expressions?tab=practice

**Approach:** Keep ε distinct from ∅. → Test short boundary words. → Use language identities or equivalent automata.

**Worked solution:**
1. The first symbol must be 1 to move from start s to accepting p; a first 0 goes to the rejecting sink r.

#### Q15 · MCQ · 1 mark(s) · Recurrence relations

Study: /#/lesson/recurrences?tab=practice

**Approach:** Compute initial terms. → Find characteristic roots and particular terms. → Apply all initial conditions and substitute back.

**Worked solution:**

2. The sequence αⁿ+βⁿ obeys the recurrence since each root satisfies r²=r+1. At n=1 it is α+β=1; at n=2 it is (α+β)²−2αβ=3.

#### Q17 · MCQ · 1 mark(s) · Link flow control and ARQ

Study: /#/lesson/flow-control-arq?tab=practice

**Approach:** Draw frame/ACK timelines. → Identify retransmission policy. → Check window versus sequence-space constraints.

**Worked solution:**

2. A longer link increases propagation time. A higher transmission rate reduces the time to send a fixed packet. Both increase the ratio Tprop/Ttx.
3. Utilization is therefore lowest for a **longer link and higher rate**, option B.

#### Q18 · MCQ · 1 mark(s) · Determinants and invertibility

**Approach:** Track row swaps and scaling. → Reduce to triangular form. → Multiply diagonal values with accumulated factors.

**Worked solution:**

#### Q19 · MCQ · 1 mark(s) · Nondeterminism and subset construction

Study: /#/lesson/nfa?tab=practice

**Approach:** Compute ε-closure. → Move on one symbol then close again. → Mark a subset accepting if it intersects the original final states.

**Worked solution:**
1. The required language is $\text{letter}(\text{letter}\mid\text{digit})^*$. A valid identifier must consume one letter before accepting; after that, it may consume any sequence of letters and digits.
2. In **(A)**, the lower $\epsilon$ arrow goes from the start state directly to the accepting state. It bypasses the compulsory first letter. The machine therefore accepts the empty string and a digit-only string such as `1`, which are invalid identifiers.
3. In **(B)**, after the first letter the machine chooses a letters-only loop or a digits-only loop. There is no transition between these branches. Consequently it cannot accept a mixed suffix such as the suffix `1a` in `a1a`.
4. In **(C)**, the first transition consumes a letter and reaches an accepting state. From there, epsilon branches choose a letter or a digit; the rightmost state returns by epsilon to the accepting state. Each repetition may choose either branch independently. This accepts exactly the required language, including a single letter and arbitrary mixed suffixes.
5. In **(D)**, the feedback cycle consumes a letter followed by a digit as a pair. After the compulsory initial letter, strings such as `aa` and `a1` cannot finish in the accepting state.
6. Therefore **(C)** is the only correct automaton.

#### Q20 · MCQ · 1 mark(s) · Hashing and collision resolution

Study: /#/lesson/hashing?tab=practice

**Approach:** Compute the initial bucket. → Simulate probes modulo capacity. → Preserve tombstones and check load assumptions.

**Worked solution:**
1. A deterministic publicly known division or multiplication hash can be defeated by choosing many keys with the same hash value. Choosing constants carefully does not remove that adversarial knowledge.
2. Universal hashing selects a function randomly from a family whose collision probability for any two distinct fixed keys is bounded.
3. This makes collision guarantees independent of the adversary’s fixed key set. Choose **C**; it does not promise zero collisions when k>m.

#### Q21 · MCQ · 1 mark(s) · Latches and flip-flops

Study: /#/lesson/latches-flipflops?tab=practice

**Approach:** Identify level versus edge sensitivity. → Mark sampling windows or edges. → Apply characteristic equations using the old state.

**Worked solution:**
1. Let D be input 1. The feedback connection puts Q on input 0, giving Q(next)=S·D+¬S·Q.
2. When S=1, the output follows D. When S=0, the feedback retains the previous output.
